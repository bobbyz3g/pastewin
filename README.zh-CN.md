# PasteWin

[English](README.md) | 简体中文

PasteWin 是一款 Windows 本地剪贴板历史工具。保存复制过的文字和图片，通过快捷键搜索、选择并粘贴回原应用。历史记录保存在本机，无需账号。

项目目前处于早期阶段。应用和安装程序当前使用中文界面。

## 主要功能

- **文字与图片历史**：保存纯文本和静态位图，自动去重，重启后仍可使用。
- **快捷访问**：按 **Ctrl+Shift+V** 打开紧凑浮动面板，搜索文字并选择记录。
- **粘贴回原应用**：将内容插入唤起面板前所在窗口的光标位置。
- **收藏与清理**：收藏常用内容、删除单条记录，或清除未收藏记录。
- **后台运行**：在托盘记录，可暂停捕获，也可选择开机自启。
- **本地存储**：历史保存在本机，不上传剪贴板内容。

## 安装与运行

PasteWin 支持 **Windows 10/11**，需要 **Microsoft Edge WebView2 Runtime**。

可以[从源码构建](#从源码构建)生成 `bin/pastewin.exe`，或[构建安装包](docs/packaging.md)生成 `bin/pastewin-<version>-<arch>-setup.exe`。

- **便携版**：直接运行 `pastewin.exe`。历史保存在 Windows 用户目录中，不在 EXE 所在目录中。
- **安装版**：运行安装包，选择安装目录和可选的桌面、开始菜单快捷方式。默认目录为 `%LOCALAPPDATA%\Programs\PasteWin`，仅为当前用户安装。如果缺少 WebView2，安装程序会运行微软引导程序，需要联网。

升级前，请从托盘菜单或设置中退出 PasteWin。升级和卸载均保留剪贴板历史。当前 EXE 和安装包尚未进行代码签名。

## 快速开始

1. 启动 PasteWin，然后在其他应用中复制文字或图片。
2. 将光标放到需要粘贴的位置，按 **Ctrl+Shift+V**。
3. 搜索，或使用 **↑ / ↓** 选择记录。
4. 按 **Enter** 粘贴回原窗口。双击记录也可粘贴。

PasteWin 只发送 **Ctrl+V**，不会额外发送 Enter 或提交消息。没有可用的目标窗口时，仍可复制记录，再手动粘贴。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+V | 打开历史面板 |
| ↑ / ↓ | 选择记录 |
| Enter | 粘贴所选记录 |
| Ctrl+Enter | 仅复制所选记录 |
| Delete | 删除所选记录；在非空搜索框或其他文字输入框中保留文字编辑行为 |
| Esc | 关闭弹窗或菜单；否则先清空搜索，再隐藏面板 |
| Shift+F10 / 菜单键 | 打开已聚焦记录的右键菜单 |

右键点击记录可收藏、取消收藏或删除。通过“查看内容”阅读全文或查看图片。同一条记录同时包含文字和图片时，默认操作使用文字，预览中提供单独的图片操作。搜索只匹配文字。弹窗打开时，Delete 不会删除记录。

关闭面板后，PasteWin 继续在托盘运行。在设置或托盘菜单中选择“退出”才会结束进程。“开机自启”默认关闭；开启后，登录 Windows 时仅进入托盘，不弹出面板。手动移动便携版后，需要重新开启自启来登记新路径。Windows 启动设置或组织策略仍可能阻止自动启动。

## 数据与限制

历史、图片和收藏保存在 `%APPDATA%\PasteWin\history.db`，采用**本地明文存储**。PasteWin 尊重支持的剪贴板排除标记，但无法识别所有密码或敏感内容。需要时可暂停捕获。

- 只记录启动后的新复制事件，不主动导入启动前或暂停期间的剪贴板内容。
- 最多保存 **500 条记录**，每条最多 **1 MiB UTF-8 文本**。容量不足时删除最旧的未收藏记录；如果 500 条全部收藏，新内容不会保留。
- 每张图片最多 **1600 万像素**，规范化后的 PNG 最多 **20 MiB**。图片和缩略图有效数据合计最多 **256 MiB**。容量不足时淘汰最旧的未收藏图片；仍无法腾出空间时拒绝新图片并提示。SQLite 数据库及日志文件可能更大，删除后不会立即缩小。
- 支持纯文本、静态 PNG 和未压缩 DIB 位图。在资源管理器中复制图片文件不等于复制位图内容。尚不支持文件历史、动图、OCR、HTML/RTF 图文还原、图片编辑和自定义快捷键。
- 连续快速复制时，可能跳过尚未处理的图片，面板会提供提示。
- 自动粘贴取决于目标应用的输入支持和 Windows 权限。管理员窗口及部分编辑器可能需要手动粘贴。图片粘贴还要求目标应用接受图片。

## 从源码构建

在 Windows 上安装 **Go 1.27.0+**、**Node.js 22.12+ 或兼容的较新版本**和 **WebView2 Runtime**，然后从仓库根目录执行：

```powershell
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.25
wails3 doctor
wails3 build
```

产物为 `bin/pastewin.exe`。需要实时开发时，运行 `wails3 dev`。

PasteWin 使用 Go、Wails v3、React、TypeScript 和 SQLite。环境配置、界面预览、测试及源码结构见[开发指南（英文）](docs/development.md)，安装包构建及选项见 [Windows 打包指南（英文）](docs/packaging.md)。
